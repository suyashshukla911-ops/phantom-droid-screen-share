# 90-second CISO demo script

1. "This QR contains only an opaque, short-lived session credential; it is not an identity payload."
2. "Pairing is separate from authorization. The sender must complete four distinct consent stages."
3. "Only after consent is complete does the sender get the browser's native screen-share control."
4. "The viewer is receive-only. There is no mouse, keyboard, shell, file-transfer, camera or microphone control plane."
5. "The signaling service keeps session state in memory and does not write screen frames."
6. "The screen is transmitted using WebRTC after explicit browser authorization."
7. "The session has a short lifetime and ends on leave, refresh, stop-sharing or expiry."
8. "The project documents implemented controls and residual production work rather than claiming a federal authorization or certification."
