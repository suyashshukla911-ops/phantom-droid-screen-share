How to demo this quickly
For a no-install demo, use a second browser session on a desktop. Open the sender link, complete consent, then share a separate tab/window. The viewer receives that browser surface over WebRTC.
Platform boundary
A normal Android browser does not expose whole-device screen capture through this web interface. No hidden workaround is attempted; use a supported desktop browser for the live mirror demonstration.
