Two-browser rule
Browser A is the receiver. Browser B is the sender. Both must use the same temporary join link; opening the home page twice creates two unrelated sessions.
Platform boundary
The live mirror uses the browser's own Screen Capture API. Supported desktop browsers can share a selected tab, window or display. Mobile browsers may not expose whole-device capture.
